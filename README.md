# Seatfill-Analysis
Power BI dashboard and Excel dataset tracking employee seat fill metrics and occupancy rates across multiple regions.
# Regional Employee Seat Fill & Occupancy Dashboard

# Overview
This repository contains an end-to-end data analysis project analyzing employee seat fill metrics across various geographical regions. It includes the raw Excel dataset and an interactive Power BI dashboard designed to track regional occupancy rates, seat utilization, and workforce distribution.

# Repository Structure
* **Seatfill Data —** Contains the Excel dataset with regional employee and seat fill data.
* **Seatfill% Analysis —** Contains the Power BI file with interactive visual analytics.

# Key Insights & Features
**Regional Breakdown:** Comparative analysis of seat allocation and fill counts across regions.
**Occupancy Tracking:** Key performance indicators (KPIs) monitoring seat utilization rates.
**Interactive Filtering:** Slicers for deep-diving into specific locations and employee groups.
